# Negociogenesis

> A Set of Prototypes of Software Production Systems.

## Repo Model

- `main` — only this README and [`AGENTS.md`](AGENTS.md): index of projects.
- One branch per prototype. Each branch is self-contained and holds the full
  prototype (specs, code, assets).

To work on a prototype:

```sh
git checkout <project>
```

Agents: read [`AGENTS.md`](AGENTS.md) before committing or running anything.
